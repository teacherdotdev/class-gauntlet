# Bank Files use the Test Parrot Package format

A Bank File is a Test Parrot Package (`<Bank title>.parrot.zip`: `parrot.json` plus each Picture under `media/`), not a format of our own or Moodle XML, so Class Gauntlet and Test Parrot can open each other's banks and we don't own a second format. What Test Parrot has no place for (a multiple-choice explanation, a Picture's width as a share of its natural width) rides in a `classGauntlet` field that Test Parrot ignores, so a Class Gauntlet round trip loses nothing. GIFs and SVGs are written as they are, though Test Parrot refuses them, because animated ASL signs matter more than opening the file in Test Parrot. The reader and writer live in Class Gauntlet, tested against Test Parrot's published schemas and examples, until Question Commons can hold display math and take them over.
