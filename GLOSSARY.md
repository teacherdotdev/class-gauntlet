# Class Gauntlet

A classroom review game: a teacher hosts from one tab, students join on their own devices, and the class plays through review questions in one of several Game Modes.

## Language

### Hosting

**Session**:
One hosted room, from opening the lobby to the final standings, played in one Game Mode under one PIN.
_Avoid_: Room, match

**Game Mode**:
The rules a Session is played by. The teacher picks it first, then sets the Session up for it.
_Avoid_: Game type, variant

**Question Bank**:
A named collection of questions a teacher keeps in their library; the same thing Question Commons reads from a file.
_Avoid_: Question set, deck, quiz

**Topic**:
A concept a question covers, as Question Commons names it. A question can have several, and a Topic gathers questions from across Question Banks.
_Avoid_: Tag, category

**Rich Text**:
A question's words with formatting, math and pictures, in the shape Question Commons uses. Every question also keeps them as plain text, for search, spreadsheets and History. A picture lives in the teacher's browser and is sent to each phone that needs it.

**History**:
The record, kept in the teacher's browser, of every finished Session: when, which Game Mode, and how each student or Team placed.

**Backup**:
One file holding everything the teacher's browser keeps: Question Banks, History, and each Game Mode's remembered rules and setup. Importing a Backup replaces it all. A Game Mode's rules are set while hosting it and remembered for next time; Settings holds only the Backup.

### Champion

**Champion**:
The Game Mode where one student, the Champion, holds the field against the rest of the class.
_Avoid_: Challenger, Gauntlet, 1v100, Spotlight Player, The One

**The Class**:
Everyone in a Champion game who is still challenging the Champion.
_Avoid_: Mob

**Comeback Crew**:
Students who missed a question the Champion got right, and play on for smaller points.
_Avoid_: Crowd

### Classic

**Classic**:
The plain Game Mode: everyone answers every question on their own device, and the teacher sees who understood what. Scoring is optional.
_Avoid_: Quiz, live quiz, Kahoot

**Report**:
What Classic shows the teacher at the end: how the class did on each question and how each student did.

### Peril!

**Peril!**:
The Game Mode played on a board of tiles, after Jeopardy, with a medieval theme.
_Avoid_: Jeopardy

**Board**:
The grid of Tiles a Peril! game is played on, built by the teacher from questions in their Question Banks.

**Column**:
A titled stack of five Tiles, rising in value from top to bottom.
_Avoid_: Category

**Tile**:
One question on the Board, worth a set number of points.
_Avoid_: Square, clue

**Control**:
The right to pick the next Tile, held by whoever last answered correctly.

**Buzz**:
Claiming the right to answer an open Tile; the first Buzz to reach the teacher wins it.

**Treasure Trove**:
A hidden Tile where whoever picks it makes a Wager and answers alone.
_Avoid_: Daily Double

**Solo**:
Peril! played with each student scoring for themselves.

**Team**:
A named group of students who score together in Peril!.
_Avoid_: Group, house

**Team Vote**:
How a Team answers: every member votes for a choice, and the choice with the most votes is the Team's answer.

**Wager**:
Points a student or Team stakes on a Treasure Trove before seeing its question.
_Avoid_: Bet
